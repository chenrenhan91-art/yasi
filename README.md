# 口语对练

雅思口语练习和日常英语对练。考官按 Part 1、Part 2、Part 3 提问。陪练不设题目，顺着你的话往下聊。

## 启动

双击 `启动雅思口语对练.command`，浏览器会打开 `http://localhost:8765`。也可以用 Chrome 或 Edge 直接打开 `index.html`。没有本地语音服务时，会改用浏览器朗读。

## 怎么用

- **考官**：Claire Hargreaves。点「随机选题」从题库换一套。Part 2 有题卡和计时。没有某一部分的题，不会临时编一张题卡。
- **陪练**：Maya。不选题，自然问答。
- 说完一句后，右侧给出修正句和错误对比。高分说法需要点开。发音没有测量，报告里不打发音分。
- 人声、语速、盲听和中文在回答区。语料、报告和语音模型在顶栏。

题库里的「考生回忆」来自公开的考后回忆，包括 2026 年 9–12 月的题干，不是雅思官方试卷。中文是练习译文。
