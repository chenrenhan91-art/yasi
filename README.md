# IELTS Speaking AI Studio · 雅思口语实时对练与智能纠错工作台

专为雅思口语备考与日常英语流利度训练打造的双 Agent 实时语音对练工具。

## 一、 快速启动方式

1. **方式一（推荐，支持浏览器记住麦克风权限）**：
   双击项目文件夹中的 [`启动雅思口语对练.command`](file:///Users/yuzai/Desktop/雅思口语/启动雅思口语对练.command)，脚本会自动启动本地轻量服务并在浏览器打开 `http://localhost:8765`。
2. **方式二（免服务直接打开）**：
   使用 Chrome 或 Edge 浏览器直接打开 [`index.html`](file:///Users/yuzai/Desktop/雅思口语/index.html) 即可立即开始练习。

## 二、 核心功能一览

- **双 Agent 自由切换**：
  - **🎓 雅思官方模考官 (Dr. Arthur Pendelton)**：严格按照 Part 1（日常问答）、Part 2（1分钟准备 + 2分钟个人陈述题卡）、Part 3（深度思辨追问）流程推进，语调克制专业。
  - **☕ 日常闲聊陪练伙伴 (Maya Lin)**：无考试规则束缚，涵盖好友寒暄、咖啡馆偶遇、影视音乐、海外校园/职场社交等场景，专注地道习语与自然互动。
- **右侧实时字幕流 & 后台静默并行纠错**：
  - 你说完每一句话后，考官/伙伴立即接话不打断对话节奏。
  - 同时后台并行完成语法诊断，在你的发言气泡下方自动生成 **地道修正句**、**中式英语/语法错误对比解析** 以及 **Band 7.0 / Band 8.0 高分替代表达**。
- **口音、语速与盲听训练控制**：
  - 支持 **🇬🇧 英式发音 (UK)** 与 **🇺🇸 美式发音 (US)** 一键切换。
  - 支持 **0.8x ～ 1.2x** 五档语速调节。
  - 支持 **🎧 遮挡考官英文字幕（纯练听力模式）**，开启后考官字幕自动高斯模糊，鼠标悬停或点击单句气泡可临时偷看。
- **五大雅思提分便利套件**：
  1. **Band 7+ 句型升级**：每轮发言自动提供 Band 7.0 与 Band 8.0 两个层级的同义高分改写并高亮核心词伙。
  2. **内置当季高频题库 + 自定义题卡**：内置全真模考套题及 Part 1/2/3 高频题卡（含 Part 2 专属 1 分钟准备/2 分钟陈述计时器与速记草稿板），支持自定义添加新题卡。
  3. **💡 卡壳急救提示 (Hint Generator)**：不知如何作答时点击即可获取 3 个高分搭配、2 个破题切入点和 2 个万用高分开头句（点击词伙可直接填入回答框）。
  4. **📊 四维模考评分报告**：依据雅思官方 FC（流利度与连贯性）、LR（词汇多样性）、GRA（语法多样性及准确性）、P（发音与自然度）出具分项评分与提分建议。
  5. **📚 错题与高分语料本**：支持一键收藏纠错记录与高分升级句，并支持导出为 **Markdown (.md)** 或 **Excel 兼容表格 (.csv)**。
